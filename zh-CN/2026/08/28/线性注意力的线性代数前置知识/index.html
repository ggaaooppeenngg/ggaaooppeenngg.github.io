1. Householder 矩阵

1.1 定义

设 u∈Rn\bm{u} \in \mathbb{R}^nu∈Rn 且 u⊺u=1\bm{u}^{\intercal}\bm{u} = 1u⊺u=1（即 ∥u∥2=1\|\bm{u}\|_2 = 1∥u∥2​=1），定义

H=I−2uu⊺∈Rn×n\mathbf{H} = \mathbf{I} - 2\bm{u}\bm{u}^{\intercal} \in \mathbb{R}^{n \times n} H=I−2uu⊺∈Rn×n

1.1.1 矩阵形式是怎么被「提」出来的

定义式 H=I−2uu⊺\mathbf{H} = \mathbf{I} - 2\bm{u}\bm{u}^{\intercal}H=I−2uu⊺ 常被当成天降公式，其实它只是把「反射两步走」这句话提取公因子的结果。取 n=2n = 2n=2、u=e1=[1,0]⊺\bm{u} = \bm{e}_1 = [1, 0]^{\intercal}u=e1​=[1,0]⊺、x=[3,2]⊺\bm{x} = [3, 2]^{\intercal}x=[3,2]⊺ 走一遍：

几何上：u=e1\bm{u} = \bm{e}_1u=e1​ 时镜面就是 x2x_2x2​ 轴。从 x\bm{x}x 出发沿 −u-\bm{u}−u 方向走一步 −(u⊺x)u-(\bm{u}^{\intercal}\bm{x})\bm{u}−(u⊺x)u 落到镜面上（此时第一坐标归零），再走同样的一步就到 x′\bm{x}'x′。两步等长，这正是系数 2 的来源。

推导上唯一需要的一步是 u⊺x\bm{u}^{\intercal}\bm{x}u⊺x 是标量，标量与向量相乘可换序，所以 (u⊺x)u=u(u⊺x)(\bm{u}^{\intercal}\bm{x})\bm{u} = \bm{u}(\bm{u}^{\intercal}\bm{x})(u⊺x)u=u(u⊺x)。换序之后 x\bm{x}x 变成右端公因子，反着用分配律提出来：

x′=x−2(u⊺x)u=x−2u(u⊺x)=(I−2uu⊺)x=Hx\bm{x}' = \bm{x} - 2(\bm{u}^{\intercal}\bm{x})\bm{u} = \bm{x} - 2\bm{u}(\bm{u}^{\intercal}\bm{x}) = \big(\mathbf{I} - 2\bm{u}\bm{u}^{\intercal}\big)\bm{x} = \mathbf{H}\bm{x} x′=x−2(u⊺x)u=x−2u(u⊺x)=(I−2uu⊺)x=Hx

换序是全部的技巧所在：(u⊺x)u(\bm{u}^{\intercal}\bm{x})\bm{u}(u⊺x)u 里 x\bm{x}x 被夹在中间提不出来，写成 u(u⊺x)\bm{u}(\bm{u}^{\intercal}\bm{x})u(u⊺x) 后 uu⊺\bm{u}\bm{u}^{\intercal}uu⊺ 自然聚成一个矩阵。

1.2 对称性证明

H⊺=(I−2uu⊺)⊺=I⊺−2(uu⊺)⊺=I−2uu⊺=H■\mathbf{H}^{\intercal} = (\mathbf{I} - 2\bm{u}\bm{u}^{\intercal})^{\intercal} = \mathbf{I}^{\intercal} - 2(\bm{u}\bm{u}^{\intercal})^{\intercal} = \mathbf{I} - 2\bm{u}\bm{u}^{\intercal} = \mathbf{H} \qquad \blacksquare H⊺=(I−2uu⊺)⊺=I⊺−2(uu⊺)⊺=I−2uu⊺=H■

(uu⊺)⊺=(u⊺)⊺u⊺=uu⊺(\bm{u}\bm{u}^{\intercal})^{\intercal} = (\bm{u}^{\intercal})^{\intercal}\bm{u}^{\intercal} = \bm{u}\bm{u}^{\intercal} (uu⊺)⊺=(u⊺)⊺u⊺=uu⊺
