1. Householder 矩阵

1.1 定义

设 u∈Rn\bm{u} \in \mathbb{R}^nu∈Rn 且 u⊺u=1\bm{u}^{\intercal}\bm{u} = 1u⊺u=1（即 ∥u∥2=1\|\bm{u}\|_2 = 1∥u∥2​=1），定义

H=I−2uu⊺∈Rn×n\mathbf{H} = \mathbf{I} - 2\bm{u}\bm{u}^{\intercal} \in \mathbb{R}^{n \times n} H=I−2uu⊺∈Rn×n

题外一句：Householder 矩阵也是做 QR 分解的重要工具——逐列用反射把对角线以下的元素打成零，就得到 A=QR\mathbf{A} = \mathbf{Q}\mathbf{R}A=QR，比 Gram-Schmidt 数值上稳得多。

1.1.1 矩阵形式是怎么被「提」出来的

定义式 H=I−2uu⊺\mathbf{H} = \mathbf{I} - 2\bm{u}\bm{u}^{\intercal}H=I−2uu⊺ 常被当成天降公式，其实它只是把「反射两步走」这句话提取公因子的结果。取 n=2n = 2n=2、u=e1=[1,0]⊺\bm{u} = \bm{e}_1 = [1, 0]^{\intercal}u=e1​=[1,0]⊺、x=[3,2]⊺\bm{x} = [3, 2]^{\intercal}x=[3,2]⊺ 走一遍：

几何上：u=e1\bm{u} = \bm{e}_1u=e1​ 时镜面就是 x2x_2x2​ 轴。从 x\bm{x}x 出发沿 −u-\bm{u}−u 方向走一步 −(u⊺x)u-(\bm{u}^{\intercal}\bm{x})\bm{u}−(u⊺x)u 落到镜面上（此时第一坐标归零），再走同样的一步就到 x′\bm{x}'x′。两步等长，这正是系数 2 的来源。

推导上唯一需要的一步是 u⊺x\bm{u}^{\intercal}\bm{x}u⊺x 是标量，标量与向量相乘可换序，所以 (u⊺x)u=u(u⊺x)(\bm{u}^{\intercal}\bm{x})\bm{u} = \bm{u}(\bm{u}^{\intercal}\bm{x})(u⊺x)u=u(u⊺x)。换序之后 x\bm{x}x 变成右端公因子，反着用分配律提出来：

x′=x−2(u⊺x)u=x−2u(u⊺x)=(I−2uu⊺)x=Hx\bm{x}' = \bm{x} - 2(\bm{u}^{\intercal}\bm{x})\bm{u} = \bm{x} - 2\bm{u}(\bm{u}^{\intercal}\bm{x}) = \big(\mathbf{I} - 2\bm{u}\bm{u}^{\intercal}\big)\bm{x} = \mathbf{H}\bm{x} x′=x−2(u⊺x)u=x−2u(u⊺x)=(I−2uu⊺)x=Hx

换序是全部的技巧所在：(u⊺x)u(\bm{u}^{\intercal}\bm{x})\bm{u}(u⊺x)u 里 x\bm{x}x 被夹在中间提不出来，写成 u(u⊺x)\bm{u}(\bm{u}^{\intercal}\bm{x})u(u⊺x) 后 uu⊺\bm{u}\bm{u}^{\intercal}uu⊺ 自然聚成一个矩阵。

1.2 对称性证明

H⊺=(I−2uu⊺)⊺=I⊺−2(uu⊺)⊺=I−2uu⊺=H■\mathbf{H}^{\intercal} = (\mathbf{I} - 2\bm{u}\bm{u}^{\intercal})^{\intercal} = \mathbf{I}^{\intercal} - 2(\bm{u}\bm{u}^{\intercal})^{\intercal} = \mathbf{I} - 2\bm{u}\bm{u}^{\intercal} = \mathbf{H} \qquad \blacksquare H⊺=(I−2uu⊺)⊺=I⊺−2(uu⊺)⊺=I−2uu⊺=H■

关键一步用的是乘积转置法则 (AB)⊺=B⊺A⊺(\mathbf{A}\mathbf{B})^{\intercal} = \mathbf{B}^{\intercal}\mathbf{A}^{\intercal}(AB)⊺=B⊺A⊺（转置后因子次序颠倒），以及 (A⊺)⊺=A(\mathbf{A}^{\intercal})^{\intercal} = \mathbf{A}(A⊺)⊺=A：

(uu⊺)⊺=(u⊺)⊺u⊺=uu⊺(\bm{u}\bm{u}^{\intercal})^{\intercal} = (\bm{u}^{\intercal})^{\intercal}\bm{u}^{\intercal} = \bm{u}\bm{u}^{\intercal} (uu⊺)⊺=(u⊺)⊺u⊺=uu⊺

外积矩阵因此天然对称。

1.3 广义形式：把归一化收进一个系数 τ\tauτ

H=I−2uu⊺\mathbf{H} = \mathbf{I} - 2\bm{u}\bm{u}^{\intercal}H=I−2uu⊺ 要求 ∥u∥2=1\|\bm{u}\|_2 = 1∥u∥2​=1。想对任意非零 u\bm{u}u 都能写，把归一化带在系数里就行：

H=I−2uu⊺u⊺u=I+τ uu⊺,τ:=−2u⊺u\mathbf{H} = \mathbf{I} - \frac{2\bm{u}\bm{u}^{\intercal}}{\bm{u}^{\intercal}\bm{u}} = \mathbf{I} + \tau\,\bm{u}\bm{u}^{\intercal}, \qquad \tau := -\frac{2}{\bm{u}^{\intercal}\bm{u}} H=I−u⊺u2uu⊺​=I+τuu⊺,τ:=−u⊺u2​

把 τ\tauτ 当成一个普通标量系数写在外积前面，而不是留在分母上，后面的推导会干净很多。∥u∥2=1\|\bm{u}\|_2 = 1∥u∥2​=1 时 τ=−2\tau = -2τ=−2，退回 §1.1 的定义。

系数取 −2/(u⊺u)-2/(\bm{u}^{\intercal}\bm{u})−2/(u⊺u) 不是美学选择，而是被「H\mathbf{H}H 是反射」逆推出来的。反射必须满足对合性 H2=I\mathbf{H}^2 = \mathbf{I}H2=I（照两次镜子回到原处），展开：

(I+τuu⊺)2=I+2τuu⊺+τ2u(u⊺u)⏟标量u⊺=I+τ(2+τ u⊺u)uu⊺(\mathbf{I} + \tau\bm{u}\bm{u}^{\intercal})^2 = \mathbf{I} + 2\tau\bm{u}\bm{u}^{\intercal} + \tau^2\bm{u}\underbrace{(\bm{u}^{\intercal}\bm{u})}_{\text{标量}}\bm{u}^{\intercal} = \mathbf{I} + \tau\big(2 + \tau\,\bm{u}^{\intercal}\bm{u}\big)\bm{u}\bm{u}^{\intercal} (I+τuu⊺)2=I+2τuu⊺+τ2u标量(u⊺u)​​u⊺=I+τ(2+τu⊺u)uu⊺

要它等于 I\mathbf{I}I，就要 τ(2+τu⊺u)=0\tau(2 + \tau\bm{u}^{\intercal}\bm{u}) = 0τ(2+τu⊺u)=0，除去平常解 τ=0\tau = 0τ=0 只剩

τ=−2u⊺u\tau = -\frac{2}{\bm{u}^{\intercal}\bm{u}} τ=−u⊺u2​

所以 τ\tauτ 取任何值时 H\mathbf{H}H 都对称（外积天然对称，与系数无关），但只有这一个 τ\tauτ 才让它成为对合的正交反射、才有「沿法向走两步等长」的几何意义。其余 τ\tauτ 给出的是一般的秩一修正 I+τuu⊺\mathbf{I} + \tau\bm{u}\bm{u}^{\intercal}I+τuu⊺，不再是等距变换；但 §3 的推导对 τ\tauτ 不做任何限制，对这类一般秩一修正同样成立。

2. WY 表达式：把一串反射压成一个低秩修正

结论先给：ppp 个 Householder 反射的乘积，永远能写成单位矩阵加一个秩不超过 ppp 的修正

H1H2⋯Hp=I+WY⊺,W, Y∈Rn×p\mathbf{H}_1\mathbf{H}_2\cdots\mathbf{H}_p = \mathbf{I} + \mathbf{W}\mathbf{Y}^{\intercal}, \qquad \mathbf{W},\,\mathbf{Y} \in \mathbb{R}^{n \times p} H1​H2​⋯Hp​=I+WY⊺,W,Y∈Rn×p

证明用归纳构造，一列一列把反射「吸收」进 W,Y\mathbf{W},\mathbf{Y}W,Y。

2.1 基例 p=1p = 1p=1

H1=I−2u1u1⊺=I+W1Y1⊺\mathbf{H}_1 = \mathbf{I} - 2\bm{u}_1\bm{u}_1^{\intercal} = \mathbf{I} + \mathbf{W}_1\mathbf{Y}_1^{\intercal}H1​=I−2u1​u1⊺​=I+W1​Y1⊺​，取

W1=[−2u1],Y1=[u1]\mathbf{W}_1 = \big[-2\bm{u}_1\big], \qquad \mathbf{Y}_1 = \big[\bm{u}_1\big] W1​=[−2u1​],Y1​=[u1​]

均为 n×1n \times 1n×1。命题对 p=1p = 1p=1 成立。

2.2 归纳步：一列一列「吸收」反射

归纳假设：已存在 Wk, Yk∈Rn×k\mathbf{W}_k,\,\mathbf{Y}_k \in \mathbb{R}^{n \times k}Wk​,Yk​∈Rn×k 使 H1⋯Hk=I+WkYk⊺\mathbf{H}_1\cdots\mathbf{H}_k = \mathbf{I} + \mathbf{W}_k\mathbf{Y}_k^{\intercal}H1​⋯Hk​=I+Wk​Yk⊺​。要证 H1⋯HkHk+1\mathbf{H}_1\cdots\mathbf{H}_k\mathbf{H}_{k+1}H1​⋯Hk​Hk+1​ 也能写成 I+Wk+1Yk+1⊺\mathbf{I} + \mathbf{W}_{k+1}\mathbf{Y}_{k+1}^{\intercal}I+Wk+1​Yk+1⊺​，其中 Wk+1,Yk+1∈Rn×(k+1)\mathbf{W}_{k+1},\mathbf{Y}_{k+1} \in \mathbb{R}^{n \times (k+1)}Wk+1​,Yk+1​∈Rn×(k+1)。

记新反射方向 u=uk+1\bm{u} = \bm{u}_{k+1}u=uk+1​，并记

w:=−2 (I+WkYk⊺) u\bm{w} := -2\,(\mathbf{I} + \mathbf{W}_k\mathbf{Y}_k^{\intercal})\,\bm{u} w:=−2(I+Wk​Yk⊺​)u

则把 (I+WkYk⊺)(I−2uu⊺)(\mathbf{I} + \mathbf{W}_k\mathbf{Y}_k^{\intercal})(\mathbf{I} - 2\bm{u}\bm{u}^{\intercal})(I+Wk​Yk⊺​)(I−2uu⊺) 乘开后的四项可以合并（用 (I+WkYk⊺)uu⊺=[(I+WkYk⊺)u]u⊺(\mathbf{I} + \mathbf{W}_k\mathbf{Y}_k^{\intercal})\bm{u}\bm{u}^{\intercal} = \big[(\mathbf{I} + \mathbf{W}_k\mathbf{Y}_k^{\intercal})\bm{u}\big]\bm{u}^{\intercal}(I+Wk​Yk⊺​)uu⊺=[(I+Wk​Yk⊺​)u]u⊺，u⊺\bm{u}^{\intercal}u⊺ 原样留在最右）

I+WkYk⊺−2uu⊺−2WkYk⊺uu⊺=I+WkYk⊺+wu⊺\mathbf{I} + \mathbf{W}_k\mathbf{Y}_k^{\intercal} - 2\bm{u}\bm{u}^{\intercal} - 2\mathbf{W}_k\mathbf{Y}_k^{\intercal}\bm{u}\bm{u}^{\intercal} = \mathbf{I} + \mathbf{W}_k\mathbf{Y}_k^{\intercal} + \bm{w}\bm{u}^{\intercal} I+Wk​Yk⊺​−2uu⊺−2Wk​Yk⊺​uu⊺=I+Wk​Yk⊺​+wu⊺

于是

H1⋯Hk+1=I+[ Wk    w ][ Yk    u ]⊺\mathbf{H}_1\cdots\mathbf{H}_{k+1} = \mathbf{I} + \big[\,\mathbf{W}_k \;\; \bm{w}\,\big]\big[\,\mathbf{Y}_k \;\; \bm{u}\,\big]^{\intercal} H1​⋯Hk+1​=I+[Wk​w][Yk​u]⊺

即 Wk+1=[Wk, w]\mathbf{W}_{k+1} = [\mathbf{W}_k,\ \bm{w}]Wk+1​=[Wk​, w]，Yk+1=[Yk, uk+1]\mathbf{Y}_{k+1} = [\mathbf{Y}_k,\ \bm{u}_{k+1}]Yk+1​=[Yk​, uk+1​]。定理得证。■\blacksquare■

3. compact WY：把纠缠收进一个上三角因子 T\mathbf{T}T

WY 有个不便：W\mathbf{W}W 的列互相纠缠。由 §2.2 的递推回代可得 wt=−2H1⋯Ht−1ut\bm{w}_t = -2\mathbf{H}_1\cdots\mathbf{H}_{t-1}\bm{u}_twt​=−2H1​⋯Ht−1​ut​，每根列都带着一个前缀乘积，W\mathbf{W}W 里存的已经不是原始法向了。

1989 年 Schreiber–Van Loan 的 compact WY 把全部纠缠塞进一个 p×pp \times pp×p 小矩阵，让两个 n×pn \times pn×p 因子里只剩下原始法向：

H1⋯Hp=I+YTY⊺,Y=[ u1,…,up ],T∈Rp×p 上三角\mathbf{H}_1\cdots\mathbf{H}_p = \mathbf{I} + \mathbf{Y}\mathbf{T}\mathbf{Y}^{\intercal}, \qquad \mathbf{Y} = [\,\bm{u}_1, \dots, \bm{u}_p\,], \quad \mathbf{T} \in \mathbb{R}^{p \times p}\ \text{上三角} H1​⋯Hp​=I+YTY⊺,Y=[u1​,…,up​],T∈Rp×p 上三角

下面用 §1.3 的广义形式 H=I+τuu⊺\mathbf{H} = \mathbf{I} + \tau\bm{u}\bm{u}^{\intercal}H=I+τuu⊺ 写，ut\bm{u}_tut​ 不需归一，τt\tau_tτt​ 也不限于 −2/(ut⊺ut)-2/(\bm{u}_t^{\intercal}\bm{u}_t)−2/(ut⊺​ut​)，当成一串给定系数即可。

递推构造：

T1=[τ1],Tk+1=[Tkτk+1 Tk (Yk⊺uk+1)0τk+1]\mathbf{T}_1 = [\tau_1], \qquad \mathbf{T}_{k+1} = \begin{bmatrix} \mathbf{T}_k & \tau_{k+1}\,\mathbf{T}_k\,(\mathbf{Y}_k^{\intercal}\bm{u}_{k+1}) \\ \bm{0} & \tau_{k+1} \end{bmatrix} T1​=[τ1​],Tk+1​=[Tk​0​τk+1​Tk​(Yk⊺​uk+1​)τk+1​​]

证明与 §2.2 是同一个机制，只是新增的一列不往 nnn 维因子里塞，而往 T\mathbf{T}T 里塞。记 u=uk+1\bm{u} = \bm{u}_{k+1}u=uk+1​、τ=τk+1\tau = \tau_{k+1}τ=τk+1​，乘开：

(I+YkTkYk⊺)(I+τuu⊺)=I+YkTkYk⊺+τuu⊺+τ YkTk(Yk⊺u) u⊺(\mathbf{I} + \mathbf{Y}_k\mathbf{T}_k\mathbf{Y}_k^{\intercal})(\mathbf{I} + \tau\bm{u}\bm{u}^{\intercal}) = \mathbf{I} + \mathbf{Y}_k\mathbf{T}_k\mathbf{Y}_k^{\intercal} + \tau\bm{u}\bm{u}^{\intercal} + \tau\,\mathbf{Y}_k\mathbf{T}_k(\mathbf{Y}_k^{\intercal}\bm{u})\,\bm{u}^{\intercal} (I+Yk​Tk​Yk⊺​)(I+τuu⊺)=I+Yk​Tk​Yk⊺​+τuu⊺+τYk​Tk​(Yk⊺​u)u⊺

三个修正项正好是 [Yk, u]\big[\mathbf{Y}_k,\, \bm{u}\big][Yk​,u] 夹一个 (k+1)×(k+1)(k+1) \times (k+1)(k+1)×(k+1) 矩阵再夹 [Yk, u]⊺\big[\mathbf{Y}_k,\, \bm{u}\big]^{\intercal}[Yk​,u]⊺ 的展开结果：YkTkYk⊺\mathbf{Y}_k\mathbf{T}_k\mathbf{Y}_k^{\intercal}Yk​Tk​Yk⊺​ 对应左上块，τuu⊺\tau\bm{u}\bm{u}^{\intercal}τuu⊺ 对应右下角，交叉项 τYkTk(Yk⊺u)u⊺\tau\mathbf{Y}_k\mathbf{T}_k(\mathbf{Y}_k^{\intercal}\bm{u})\bm{u}^{\intercal}τYk​Tk​(Yk⊺​u)u⊺ 对应右上列，左下为零：

=I+[Yk, u][TkτTk(Yk⊺u)0τ][Yk, u]⊺= \mathbf{I} + \big[\mathbf{Y}_k,\, \bm{u}\big] \begin{bmatrix} \mathbf{T}_k & \tau\mathbf{T}_k(\mathbf{Y}_k^{\intercal}\bm{u}) \\ \bm{0} & \tau \end{bmatrix} \big[\mathbf{Y}_k,\, \bm{u}\big]^{\intercal} =I+[Yk​,u][Tk​0​τTk​(Yk⊺​u)τ​][Yk​,u]⊺

即 Yk+1=[Yk, uk+1]\mathbf{Y}_{k+1} = [\mathbf{Y}_k,\ \bm{u}_{k+1}]Yk+1​=[Yk​, uk+1​]、Tk+1\mathbf{T}_{k+1}Tk+1​ 如上，定理得证。■\blacksquare■

三个副产品直接从递推读出来：

  • T\mathbf{T}T 上三角。左下块永远是 0\bm{0}0，上三角性逐层遗传。
  • 对角线就是系数。diag(T)=(τ1,…,τp)\mathrm{diag}(\mathbf{T}) = (\tau_1, \dots, \tau_p)diag(T)=(τ1​,…,τp​)，单位向量情形下全是 −2-2−2。
  • 与 §2 的关系是 W=YT\mathbf{W} = \mathbf{Y}\mathbf{T}W=YT。两个表达式并不独立：compact WY 把 WY 里那些前缀乘积分解成「原始法向 ×\times× 上三角系数」。纠缠没有消失，只是从 n×pn \times pn×p 的 W\mathbf{W}W 里搬到了 p×pp \times pp×p 的 T\mathbf{T}T 里，而 p≪np \ll np≪n。

4. UT 变换：用正交条件直接解出 T\mathbf{T}T

§3 的递推是串行的：算 Tk+1\mathbf{T}_{k+1}Tk+1​ 必须先有 Tk\mathbf{T}_kTk​。Joffrain 等人（2006）指出 T\mathbf{T}T 其实有闭式，一个 Gram 矩阵就够了，他们把这个写法叫 UT 变换（U\mathbf{U}U、T\mathbf{T}T 两个因子）。

为与文献记号一致，本节写成减号形式：

Q=H1⋯Hp=I−UT−1U⊺,U=[ u1,…,up ],T 上三角\mathbf{Q} = \mathbf{H}_1\cdots\mathbf{H}_p = \mathbf{I} - \mathbf{U}\mathbf{T}^{-1}\mathbf{U}^{\intercal}, \qquad \mathbf{U} = [\,\bm{u}_1, \dots, \bm{u}_p\,],\quad \mathbf{T}\ \text{上三角} Q=H1​⋯Hp​=I−UT−1U⊺,U=[u1​,…,up​],T 上三角

对照 §3：U=Y\mathbf{U} = \mathbf{Y}U=Y，T−1=−TSVL\mathbf{T}^{-1} = -\mathbf{T}_{\text{SVL}}T−1=−TSVL​（后者对角线非零故可逆），所以这里的 T\mathbf{T}T 与 §3 的上三角因子差一个求逆和符号。以下设 U\mathbf{U}U 列满秩，并记 S=T−1\mathbf{S} = \mathbf{T}^{-1}S=T−1。

推导只用一个条件：正交性。 注意不能用对合或对称——每个 Hi\mathbf{H}_iHi​ 都对称，但转置会翻转因子次序，(H1H2)⊺=H2H1≠H1H2(\mathbf{H}_1\mathbf{H}_2)^{\intercal} = \mathbf{H}_2\mathbf{H}_1 \ne \mathbf{H}_1\mathbf{H}_2(H1​H2​)⊺=H2​H1​=H1​H2​，两面镜子依次反射是一个旋转。而正交矩阵之积仍正交，Q⊺Q=I\mathbf{Q}^{\intercal}\mathbf{Q} = \mathbf{I}Q⊺Q=I 一定成立，代入展开：

(I−US⊺U⊺)(I−USU⊺)=I+U(−S⊺−S+S⊺(U⊺U)S)U⊺=I(\mathbf{I} - \mathbf{U}\mathbf{S}^{\intercal}\mathbf{U}^{\intercal})(\mathbf{I} - \mathbf{U}\mathbf{S}\mathbf{U}^{\intercal}) = \mathbf{I} + \mathbf{U}\big(-\mathbf{S}^{\intercal} - \mathbf{S} + \mathbf{S}^{\intercal}(\mathbf{U}^{\intercal}\mathbf{U})\mathbf{S}\big)\mathbf{U}^{\intercal} = \mathbf{I} (I−US⊺U⊺)(I−USU⊺)=I+U(−S⊺−S+S⊺(U⊺U)S)U⊺=I
