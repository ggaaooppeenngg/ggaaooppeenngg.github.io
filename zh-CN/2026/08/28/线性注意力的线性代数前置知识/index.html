1. Householder 矩阵

1.1 定义

设 u∈Rn\bm{u} \in \mathbb{R}^nu∈Rn 且 u⊺u=1\bm{u}^{\intercal}\bm{u} = 1u⊺u=1（即 ∥u∥2=1\|\bm{u}\|_2 = 1∥u∥2​=1），定义

H=I−2uu⊺∈Rn×n\mathbf{H} = \mathbf{I} - 2\bm{u}\bm{u}^{\intercal} \in \mathbb{R}^{n \times n} H=I−2uu⊺∈Rn×n

题外一句：Householder 矩阵也是做 QR 分解的重要工具——逐列用反射把对角线以下的元素打成零，就得到 A=QR\mathbf{A} = \mathbf{Q}\mathbf{R}A=QR，比 Gram-Schmidt 数值上稳得多。

1.1.1 矩阵形式是怎么被「提」出来的

定义式 H=I−2uu⊺\mathbf{H} = \mathbf{I} - 2\bm{u}\bm{u}^{\intercal}H=I−2uu⊺ 常被当成天降公式，其实它只是把「反射两步走」这句话提取公因子的结果。取 n=2n = 2n=2、u=e1=[1,0]⊺\bm{u} = \bm{e}_1 = [1, 0]^{\intercal}u=e1​=[1,0]⊺、x=[3,2]⊺\bm{x} = [3, 2]^{\intercal}x=[3,2]⊺ 走一遍：

几何上：u=e1\bm{u} = \bm{e}_1u=e1​ 时镜面就是 x2x_2x2​ 轴。从 x\bm{x}x 出发沿 −u-\bm{u}−u 方向走一步 −(u⊺x)u-(\bm{u}^{\intercal}\bm{x})\bm{u}−(u⊺x)u 落到镜面上（此时第一坐标归零），再走同样的一步就到 x′\bm{x}'x′。两步等长，这正是系数 2 的来源。

推导上唯一需要的一步是 u⊺x\bm{u}^{\intercal}\bm{x}u⊺x 是标量，标量与向量相乘可换序，所以 (u⊺x)u=u(u⊺x)(\bm{u}^{\intercal}\bm{x})\bm{u} = \bm{u}(\bm{u}^{\intercal}\bm{x})(u⊺x)u=u(u⊺x)。换序之后 x\bm{x}x 变成右端公因子，反着用分配律提出来：

x′=x−2(u⊺x)u=x−2u(u⊺x)=(I−2uu⊺)x=Hx\bm{x}' = \bm{x} - 2(\bm{u}^{\intercal}\bm{x})\bm{u} = \bm{x} - 2\bm{u}(\bm{u}^{\intercal}\bm{x}) = \big(\mathbf{I} - 2\bm{u}\bm{u}^{\intercal}\big)\bm{x} = \mathbf{H}\bm{x} x′=x−2(u⊺x)u=x−2u(u⊺x)=(I−2uu⊺)x=Hx

换序是全部的技巧所在：(u⊺x)u(\bm{u}^{\intercal}\bm{x})\bm{u}(u⊺x)u 里 x\bm{x}x 被夹在中间提不出来，写成 u(u⊺x)\bm{u}(\bm{u}^{\intercal}\bm{x})u(u⊺x) 后 uu⊺\bm{u}\bm{u}^{\intercal}uu⊺ 自然聚成一个矩阵。

1.2 对称性证明

H⊺=(I−2uu⊺)⊺=I⊺−2(uu⊺)⊺=I−2uu⊺=H■\mathbf{H}^{\intercal} = (\mathbf{I} - 2\bm{u}\bm{u}^{\intercal})^{\intercal} = \mathbf{I}^{\intercal} - 2(\bm{u}\bm{u}^{\intercal})^{\intercal} = \mathbf{I} - 2\bm{u}\bm{u}^{\intercal} = \mathbf{H} \qquad \blacksquare H⊺=(I−2uu⊺)⊺=I⊺−2(uu⊺)⊺=I−2uu⊺=H■

关键一步用的是乘积转置法则 (AB)⊺=B⊺A⊺(\mathbf{A}\mathbf{B})^{\intercal} = \mathbf{B}^{\intercal}\mathbf{A}^{\intercal}(AB)⊺=B⊺A⊺（转置后因子次序颠倒），以及 (A⊺)⊺=A(\mathbf{A}^{\intercal})^{\intercal} = \mathbf{A}(A⊺)⊺=A：

(uu⊺)⊺=(u⊺)⊺u⊺=uu⊺(\bm{u}\bm{u}^{\intercal})^{\intercal} = (\bm{u}^{\intercal})^{\intercal}\bm{u}^{\intercal} = \bm{u}\bm{u}^{\intercal} (uu⊺)⊺=(u⊺)⊺u⊺=uu⊺

外积矩阵因此天然对称。

2. WY 表达式：把一串反射压成一个低秩修正

结论先给：ppp 个 Householder 反射的乘积，永远能写成单位矩阵加一个秩不超过 ppp 的修正

H1H2⋯Hp=I+WY⊺,W, Y∈Rn×p\mathbf{H}_1\mathbf{H}_2\cdots\mathbf{H}_p = \mathbf{I} + \mathbf{W}\mathbf{Y}^{\intercal}, \qquad \mathbf{W},\,\mathbf{Y} \in \mathbb{R}^{n \times p} H1​H2​⋯Hp​=I+WY⊺,W,Y∈Rn×p

证明用归纳构造，一列一列把反射「吸收」进 W,Y\mathbf{W},\mathbf{Y}W,Y。

2.1 基例 p=1p = 1p=1

H1=I−2u1u1⊺=I+W1Y1⊺\mathbf{H}_1 = \mathbf{I} - 2\bm{u}_1\bm{u}_1^{\intercal} = \mathbf{I} + \mathbf{W}_1\mathbf{Y}_1^{\intercal}H1​=I−2u1​u1⊺​=I+W1​Y1⊺​，取

W1=[−2u1],Y1=[u1]\mathbf{W}_1 = \big[-2\bm{u}_1\big], \qquad \mathbf{Y}_1 = \big[\bm{u}_1\big] W1​=[−2u1​],Y1​=[u1​]

均为 n×1n \times 1n×1。命题对 p=1p = 1p=1 成立。

2.2 归纳步：一列一列「吸收」反射

归纳假设：已存在 Wk, Yk∈Rn×k\mathbf{W}_k,\,\mathbf{Y}_k \in \mathbb{R}^{n \times k}Wk​,Yk​∈Rn×k 使 H1⋯Hk=I+WkYk⊺\mathbf{H}_1\cdots\mathbf{H}_k = \mathbf{I} + \mathbf{W}_k\mathbf{Y}_k^{\intercal}H1​⋯Hk​=I+Wk​Yk⊺​。要证 H1⋯HkHk+1\mathbf{H}_1\cdots\mathbf{H}_k\mathbf{H}_{k+1}H1​⋯Hk​Hk+1​ 也能写成 I+Wk+1Yk+1⊺\mathbf{I} + \mathbf{W}_{k+1}\mathbf{Y}_{k+1}^{\intercal}I+Wk+1​Yk+1⊺​，其中 Wk+1,Yk+1∈Rn×(k+1)\mathbf{W}_{k+1},\mathbf{Y}_{k+1} \in \mathbb{R}^{n \times (k+1)}Wk+1​,Yk+1​∈Rn×(k+1)。

记新反射方向 u=uk+1\bm{u} = \bm{u}_{k+1}u=uk+1​，直接乘开得四项：

(I+WkYk⊺)(I−2uu⊺)=I+WkYk⊺− 2uu⊺−2WkYk⊺uu⊺⏟要并入一个秩 (k+1) 修正(\mathbf{I} + \mathbf{W}_k\mathbf{Y}_k^{\intercal})(\mathbf{I} - 2\bm{u}\bm{u}^{\intercal}) = \mathbf{I} + \mathbf{W}_k\mathbf{Y}_k^{\intercal} \underbrace{-\,2\bm{u}\bm{u}^{\intercal} - 2\mathbf{W}_k\mathbf{Y}_k^{\intercal}\bm{u}\bm{u}^{\intercal}}_{\text{要并入一个秩 } (k+1) \text{ 修正}} (I+Wk​Yk⊺​)(I−2uu⊺)=I+Wk​Yk⊺​要并入一个秩 (k+1) 修正−2uu⊺−2Wk​Yk⊺​uu⊺​​

看交叉项：

WkYk⊺uu⊺=Wk (Yk⊺u) u⊺\mathbf{W}_k\mathbf{Y}_k^{\intercal}\bm{u}\bm{u}^{\intercal} = \mathbf{W}_k\,(\mathbf{Y}_k^{\intercal}\bm{u})\,\bm{u}^{\intercal} Wk​Yk⊺​uu⊺=Wk​(Yk⊺​u)u⊺

关键一步（标量塌缩）：Yk⊺u∈Rk\mathbf{Y}_k^{\intercal}\bm{u} \in \mathbb{R}^kYk⊺​u∈Rk 不是矩阵，是 kkk 个标量排成的一列。所以 Wk(Yk⊺u)\mathbf{W}_k(\mathbf{Y}_k^{\intercal}\bm{u})Wk​(Yk⊺​u) 是「Wk\mathbf{W}_kWk​ 的 kkk 列按固定系数加权求和」，结果只是一根 nnn 维列向量。记

w:=−2 (I+WkYk⊺) u\bm{w} := -2\,(\mathbf{I} + \mathbf{W}_k\mathbf{Y}_k^{\intercal})\,\bm{u} w:=−2(I+Wk​Yk⊺​)u

则（用 (I+WkYk⊺)uu⊺=[(I+WkYk⊺)u]u⊺(\mathbf{I} + \mathbf{W}_k\mathbf{Y}_k^{\intercal})\bm{u}\bm{u}^{\intercal} = \big[(\mathbf{I} + \mathbf{W}_k\mathbf{Y}_k^{\intercal})\bm{u}\big]\bm{u}^{\intercal}(I+Wk​Yk⊺​)uu⊺=[(I+Wk​Yk⊺​)u]u⊺，u⊺\bm{u}^{\intercal}u⊺ 原样留在最右）

I+WkYk⊺−2uu⊺−2WkYk⊺uu⊺=I+WkYk⊺+wu⊺\mathbf{I} + \mathbf{W}_k\mathbf{Y}_k^{\intercal} - 2\bm{u}\bm{u}^{\intercal} - 2\mathbf{W}_k\mathbf{Y}_k^{\intercal}\bm{u}\bm{u}^{\intercal} = \mathbf{I} + \mathbf{W}_k\mathbf{Y}_k^{\intercal} + \bm{w}\bm{u}^{\intercal} I+Wk​Yk⊺​−2uu⊺−2Wk​Yk⊺​uu⊺=I+Wk​Yk⊺​+wu⊺

于是

H1⋯Hk+1=I+[ Wk    w ][ Yk    u ]⊺\mathbf{H}_1\cdots\mathbf{H}_{k+1} = \mathbf{I} + \big[\,\mathbf{W}_k \;\; \bm{w}\,\big]\big[\,\mathbf{Y}_k \;\; \bm{u}\,\big]^{\intercal} H1​⋯Hk+1​=I+[Wk​w][Yk​u]⊺

即 Wk+1=[Wk, w]\mathbf{W}_{k+1} = [\mathbf{W}_k,\ \bm{w}]Wk+1​=[Wk​, w]，Yk+1=[Yk, uk+1]\mathbf{Y}_{k+1} = [\mathbf{Y}_k,\ \bm{u}_{k+1}]Yk+1​=[Yk​, uk+1​]。定理得证。■\blacksquare■

交叉项塌缩就是全部机关。 秩预算 k→k+1k \to k+1k→k+1 恰好 +1，不多不少：Yk⊺u\mathbf{Y}_k^{\intercal}\bm{u}Yk⊺​u 这个 kkk 维向量被 Wk\mathbf{W}_kWk​ 吞下，没有产生新的矩阵结构；唯一新增的外积是 wu⊺\bm{w}\bm{u}^{\intercal}wu⊺ 一根。这也解释了为什么秩封顶在 ppp 而与 nnn 无关——秩的增长只由反射个数驱动，跟空间维度没关系。p≪np \ll np≪n 时（分块 QR 里典型 p=32∼128p = 32 \sim 128p=32∼128，而 nnn 可达数万），WY⊺\mathbf{W}\mathbf{Y}^{\intercal}WY⊺ 是一个极扁的低秩修正，存储从 O(n2)\mathcal{O}(n^2)O(n2) 降到 O(np)\mathcal{O}(np)O(np)。

2.3 W\mathbf{W}W 的闭式：新列带着「前面反射打过的痕迹」

把递推 wk+1=−2(I+WkYk⊺)uk+1\bm{w}_{k+1} = -2(\mathbf{I} + \mathbf{W}_k\mathbf{Y}_k^{\intercal})\bm{u}_{k+1}wk+1​=−2(I+Wk​Yk⊺​)uk+1​ 用归纳假设回代，括号里那一坨就是前 kkk 个反射的乘积：

wk+1=−2 (H1H2⋯Hk) uk+1,yk+1=uk+1\bm{w}_{k+1} = -2\,(\mathbf{H}_1\mathbf{H}_2\cdots\mathbf{H}_k)\,\bm{u}_{k+1}, \qquad \bm{y}_{k+1} = \bm{u}_{k+1} wk+1​=−2(H1​H2​⋯Hk​)uk+1​,yk+1​=uk+1​

即

W=−2 [ u1,    H1u2,    H1H2u3,    …,    H1⋯Hp−1up ]\mathbf{W} = -2\,\big[\,\bm{u}_1,\;\; \mathbf{H}_1\bm{u}_2,\;\; \mathbf{H}_1\mathbf{H}_2\bm{u}_3,\;\; \dots,\;\; \mathbf{H}_1\cdots\mathbf{H}_{p-1}\bm{u}_p\,\big] W=−2[u1​,H1​u2​,H1​H2​u3​,…,H1​⋯Hp−1​up​]

读法：Y\mathbf{Y}Y 存的是「原始方向」（各反射的法向，从未加工）；W\mathbf{W}W 存的是「被打过的方向」——第 ttt 根新列要先穿过前面 t−1t-1t−1 面镜子。如果所有镜子互不相干（即 ut⊥us, s<t\bm{u}_t \perp \bm{u}_s,\ s < tut​⊥us​, s<t），则 Hsut=ut\mathbf{H}_s\bm{u}_t = \bm{u}_tHs​ut​=ut​，wt\bm{w}_twt​ 退化为 −2ut-2\bm{u}_t−2ut​；一般情形 wt≠−2ut\bm{w}_t \ne -2\bm{u}_twt​=−2ut​，差异正是前面反射留下的痕迹。

2.4 数值验证：n=2n = 2n=2、p=2p = 2p=2 把痕迹算出来

取 u1=[1,0]⊺\bm{u}_1 = [1, 0]^{\intercal}u1​=[1,0]⊺、u2=12[1,1]⊺\bm{u}_2 = \tfrac{1}{\sqrt{2}}[1, 1]^{\intercal}u2​=2​1​[1,1]⊺（两面镜子不正交，故必有痕迹）：

H1=[−1001],H2=[0−1−10],H1H2=[01−10]\mathbf{H}_1 = \begin{bmatrix} -1 & 0 \\ 0 & 1 \end{bmatrix}, \qquad \mathbf{H}_2 = \begin{bmatrix} 0 & -1 \\ -1 & 0 \end{bmatrix}, \qquad \mathbf{H}_1\mathbf{H}_2 = \begin{bmatrix} 0 & 1 \\ -1 & 0 \end{bmatrix} H1​=[−10​01​],H2​=[0−1​−10​],H1​H2​=[0−1​10​]

按闭式算 W\mathbf{W}W、Y\mathbf{Y}Y：w2=−2H1u2=[2, −2]⊺\bm{w}_2 = -2\mathbf{H}_1\bm{u}_2 = [\sqrt{2},\, -\sqrt{2}]^{\intercal}w2​=−2H1​u2​=[2​,−2​]⊺，而 −2u2=[−2, −2]⊺-2\bm{u}_2 = [-\sqrt{2},\, -\sqrt{2}]^{\intercal}−2u2​=[−2​,−2​]⊺——第一个分量符号被 H1\mathbf{H}_1H1​ 翻了过去，这就是痕迹。

W=[−220−2],Y=[11/201/2],WY⊺=[−11−1−1]\mathbf{W} = \begin{bmatrix} -2 & \sqrt{2} \\ 0 & -\sqrt{2} \end{bmatrix}, \qquad \mathbf{Y} = \begin{bmatrix} 1 & 1/\sqrt{2} \\ 0 & 1/\sqrt{2} \end{bmatrix}, \qquad \mathbf{W}\mathbf{Y}^{\intercal} = \begin{bmatrix} -1 & 1 \\ -1 & -1 \end{bmatrix} W=[−20​2​−2​​],Y=[10​1/2​1/2​​],WY⊺=[−1−1​1−1​]

I+WY⊺=[01−10]=H1H2\mathbf{I} + \mathbf{W}\mathbf{Y}^{\intercal} = \begin{bmatrix} 0 & 1 \\ -1 & 0 \end{bmatrix} = \mathbf{H}_1\mathbf{H}_2I+WY⊺=[0−1​10​]=H1​H2​，对上了。

一句话总结：WY 表达式成立的唯一理由是 Yk⊺u\mathbf{Y}_k^{\intercal}\bm{u}Yk⊺​u 塌缩成标量向量——它让每吸收一个反射只新增一根外积 wu⊺\bm{w}\bm{u}^{\intercal}wu⊺，于是 ppp 次 level-2 反射被改写成两次 n×pn \times pn×p 的 level-3 矩阵乘；Y\mathbf{Y}Y 记原始法向，W\mathbf{W}W 记被前面镜子打过的法向。
