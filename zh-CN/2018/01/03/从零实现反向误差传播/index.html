裸写反向误差传播

发表于 2018-01-03 更新于 2026-11-24

不调用任何深度学习框架，只用 NumPy 把两层全连接网络的反向传播从头推一遍。核心结论只有一句：反向传播就是链式法则在计算图上的动态规划——每个节点只做两件事，收齐上游梯度、乘上本地雅可比，再分发给下游。

完整的 notebook 放在 HeyWhale：从零实现误差反向传播（原 klab 项目已迁移），本文把其中的推导过程整理成文字版。

1. 计算图与符号

一个带 ReLU 的两层网络，前向过程拆成五个原子操作：

符号约定：NNN 是 batch 大小，DDD 是输入维度，HHH 是隐层宽度，CCC 是类别数。W1∈RD×HW_1 \in \mathbb{R}^{D \times H}W1​∈RD×H，W2∈RH×CW_2 \in \mathbb{R}^{H \times C}W2​∈RH×C。

反向传播要算的是四个参数梯度 ∂L∂W1,∂L∂b1,∂L∂W2,∂L∂b2\frac{\partial L}{\partial W_1}, \frac{\partial L}{\partial b_1}, \frac{\partial L}{\partial W_2}, \frac{\partial L}{\partial b_2}∂W1​∂L​,∂b1​∂L​,∂W2​∂L​,∂b2​∂L​。直接从 LLL 对 W1W_1W1​ 求导会陷入冗长的下标展开；把它拆成每一步的局部导数，问题就变成四个独立的乘法。

2. 逐层推导

记 δk=∂L∂zk\delta_k = \frac{\partial L}{\partial z_k}δk​=∂zk​∂L​ 为损失对某层预激活的梯度，从输出层往回推。

第 ⑤ 步 + 第 ④ 步：softmax 与交叉熵合并。

这是整条链路里唯一需要认真算的一步。设 logits 为 zzz，概率 p=softmax(z)p = \text{softmax}(z)p=softmax(z)，交叉熵 L=−∑iyilog⁡piL = -\sum_i y_i \log p_iL=−∑i​yi​logpi​。先算 ∂L∂zj\frac{\partial L}{\partial z_j}∂zj​∂L​：

∂L∂zj=−∑iyipi⋅∂pi∂zj\frac{\partial L}{\partial z_j} = -\sum_i \frac{y_i}{p_i} \cdot \frac{\partial p_i}{\partial z_j} ∂zj​∂L​=−i∑​pi​yi​​⋅∂zj​∂pi​​

softmax 的雅可比为 ∂pi∂zj=pi(δij−pj)\frac{\partial p_i}{\partial z_j} = p_i(\delta_{ij} - p_j)∂zj​∂pi​​=pi​(δij​−pj​)，代入后：

∂L∂zj=−yj+pj∑iyi=pj−yj\frac{\partial L}{\partial z_j} = -y_j + p_j \sum_i y_i = p_j - y_j ∂zj​∂L​=−yj​+pj​i∑​yi​=pj​−yj​

用 ∑iyi=1\sum_i y_i = 1∑i​yi​=1 消掉了求和项。结论：δ2=p−y\delta_2 = p - yδ2​=p−y，一个减法搞定，这也是所有分类框架都把 softmax 和交叉熵融合成一个算子的原因。

第 ③ 步：全连接层。

z2=a1W2+b2z_2 = a_1 W_2 + b_2z2​=a1​W2​+b2​，因此：

∂L∂W2=a1⊤δ2,∂L∂b2=∑n=1Nδ2(n),δ1pre=δ2W2⊤\frac{\partial L}{\partial W_2} = a_1^\top \delta_2, \qquad \frac{\partial L}{\partial b_2} = \sum_{n=1}^{N} \delta_2^{(n)}, \qquad \delta_1^{\text{pre}} = \delta_2 W_2^\top ∂W2​∂L​=a1⊤​δ2​,∂b2​∂L​=n=1∑N​δ2(n)​,δ1pre​=δ2​W2⊤​

注意形状：δ2\delta_2δ2​ 是 [N,C][N, C][N,C]，a1⊤a_1^\topa1⊤​ 是 [H,N][H, N][H,N]，乘出来正好是 [H,C][H, C][H,C]，与 W2W_2W2​ 一致。bias 的梯度是对 batch 维求和。

第 ② 步：ReLU。

ReLU 的导数是阶梯函数，在 0 处取 0：

δ1=δ1pre⊙1[z1>0]\delta_1 = \delta_1^{\text{pre}} \odot \mathbb{1}[z_1 > 0] δ1​=δ1pre​⊙1[z1​>0]

⊙\odot⊙ 是逐元素相乘。前向时把 z1z_1z1​ 的符号掩码缓存下来，反向直接复用。

第 ① 步：第一层全连接。

与第一层同构：

∂L∂W1=x⊤δ1,∂L∂b1=∑n=1Nδ1(n)\frac{\partial L}{\partial W_1} = x^\top \delta_1, \qquad \frac{\partial L}{\partial b_1} = \sum_{n=1}^{N} \delta_1^{(n)} ∂W1​∂L​=x⊤δ1​,∂b1​∂L​=n=1∑N​δ1(n)​

至此四个梯度全部得到。可以看到每一层的反向都是同一个模板：δ下游\delta_{\text{下游}}δ下游​ 乘本地雅可比得到 δ上游\delta_{\text{上游}}δ上游​，同时用缓存的激活值算出权重梯度。

3. NumPy 实现

几个容易出错的地方：

  • d2 除以了 N，因为损失取的是 batch 均值；不除的话学习率要相应缩小 N 倍。
  • softmax 里减去行最大值，防止 exp 溢出，这是数值稳定的标准写法。
  • 求 d1 用的掩码是 self.z1 > 0（预激活的符号），不是 self.a1 > 0——虽然对 ReLU 两者等价，但写成前者才体现"本地雅可比依赖前向缓存"这条通则。
  • 参数更新时 w -= lr * g 必须原地修改或用赋值回写，写成 w = w - ... 改的是局部变量。

4. 梯度检查

手写反向传播最可靠的验证手段是数值梯度：在参数上施加微小扰动 ε\varepsilonε，用中心差分近似导数，和解析梯度比对。

把 grad_check 的结果和 backward 算出的 gW1/gW2 逐元素比较，相对误差应在 10−710^{-7}10−7 量级。如果某个元素差了好几个数量级，基本可以断定那一层的链式法则接错了。这一步能抓住 90% 的实现错误，比盯着 loss 曲线猜靠谱得多。

总结

  1. 反向传播的本质是链式法则在计算图上的复用：每层的反向模板都是「上游梯度 × 本地雅可比 + 缓存激活算权重梯度」，与网络深度无关。
  2. softmax 与交叉熵合并后的梯度是干净的 p−yp - yp−y，这是分类任务的标准起手。
  3. 用数值梯度做梯度检查，是手写反向传播时验证正确性的最快路径。

一句话总结：不要试图一步求出损失对第一层权重的导数，把它拆成每一步的局部雅可比，让梯度沿着计算图逐层回流，复杂度就从指数降到线性。
